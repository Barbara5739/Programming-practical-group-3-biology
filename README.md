# Programming-practical-group-3-biology
### To move or not to move: which nutrient conditions affect the movement of various types of bacteria the most?
This is the GitHub repository created for the programming practical PRA2003. It contains a programming project about a fictional experiment on bacteria. In the simulation, each type of bacteria has a 'normal' or wild type (marked by a positive number in the database), and also a mutant type (marked by a negative number in the same database), which may or may not move and proliferate differently under different nutrient conditions, which you can change. The Python code also shows these differences.
